# Vijay Dental Studio — premium slideshow preview

Next.js source unpacked from the original premium Vercel source archive.

## Local preview

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Production check: `npm run build`.

## Changes

Three local illustrative photographs replace remote image dependencies. The slideshow includes previous/next controls, selectors, pause/play, reduced-motion support and hidden-tab pausing. The requested care banner and unverified patient statistics/reviews are removed. Typography, colours and page layouts use an ivory, charcoal and muted burgundy direction.

Doctor credentials, patient results, opening times and a precise map are not fabricated. The appointment form is clearly a demonstration and sends/stores nothing. Confirm clinic content and connect a real booking workflow before production use. Illustrative photos are from Pexels IDs 3845981, 3845624 and 3845806; they are not photos of this clinic.

The original ZIP remains in the repository. Configure Vercel to deploy this branch at repository root for a preview; merging is not required to review the change. No production deployment is performed by this change.
